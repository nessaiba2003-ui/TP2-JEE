### TP 2 : Spring IOC

### Objectif
Ce tp a pour but de créer une application Java avec Spring...mettant en œuvre :
IOC: Délégation de la création et du cycle de vie des objets à Spring
L'Injection de Dépendances (DI) : Injection automatique des dépendances via des annotations
Développement d'une interface DAO et de ses implémentations
Création d'une couche métier
Gestion de l'injection des dépendances entre les couches
### Prérequis
Java 8 ou supérieur
Maven 3.6+
Eclipse ou IntelliJ IDEA
Connaissances de base en Programmation Orientée Objet
Notions de base en Spring Framework
## Avantages de Spring IoC/DI

Couplage faible qui se voit en tant que les composants ne créent pas leurs dépendances
Testabilité qui facile de mocker les dépendances
Maintenabilité en configuration centralisée
Flexibilité avec changement d'implémentation sans modifier le code
Réutilisabilité afin que les composants indépendants et réutilisables
